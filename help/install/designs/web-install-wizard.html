集群指标标签重要

全新安装保持默认；已有监控填写实际标签，例如 cluster。
例如 origin_prometheus="prod-k8s"：这里填标签名，接入 Agent 时再填集群标识 prod-k8s。新安装的 Agent 自动继承该标签名。
